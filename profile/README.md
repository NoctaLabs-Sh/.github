# Nocta Labs

Secure by design. Open by default.

Nocta Labs builds open-source security hardware in Leuven, Belgium. We are prototyping **Nocta One**, an offline hardware password manager with a 2.7 inch e-ink screen, and we take on hardware security research and device prototyping.

Nocta One is in prototyping. The board is on revision v3, a development board. The firmware is not written yet. Nothing is for sale.

## Repositories

- [**Nocta-One-Hardware**](https://github.com/NoctaLabs-Sh/Nocta-One-Hardware): KiCad schematic, board layout, gerbers and a sourced BOM. CERN-OHL-S v2.
- [**Nocta-One-Firmware**](https://github.com/NoctaLabs-Sh/Nocta-One-Firmware): firmware for Nocta One. Empty for now. GPL-3.0-or-later.

## Security

What the device is designed to protect against, and what it does not, is written up at [noctalabs.sh/security](https://www.noctalabs.sh/security). Report vulnerabilities privately, following the [disclosure policy](https://github.com/NoctaLabs-Sh/Nocta-One-Firmware/blob/main/SECURITY.md).
